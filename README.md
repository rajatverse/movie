# MovieTycoon

A movie studio management tycoon game built with Godot 4.x.

## Project Specifications

- **Project Name:** MovieTycoon
- **Engine:** Godot 4.x
- **Target Platform:** Android
- **Orientation:** Portrait (720x1280 viewport)

## Project Directory Structure

- `/autoloads`: Global singleton scripts (not yet registered in project settings)
- `/resources`: Custom Resource scripts and instances (.tres)
- `/data`: Game datasets
  - `/data/staff`: Staff configuration files and resource data
  - `/data/contracts`: Script and movie contract data
  - `/data/distributors`: Movie distribution network data
- `/scenes`: Main game scenes, levels, and gameplay nodes
- `/ui`: User interface components, views, and HUD elements
